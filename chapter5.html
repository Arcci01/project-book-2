Programming Concept And Logics

5.1 Programming Languages

5.1.1 Introduction

A programming language is used to give instructions to a computer and develop programs.

5.1.2 Types of Languages

Low-level languages are close to hardware, high-level languages are easy for humans, and 4GL languages require less coding and are more user-friendly.

5.1.3 Translator

A compiler translates the whole program, an interpreter translates line by line, and an assembler converts assembly language into machine code.

5.1.4 Errors

Syntax error violates programming rules, semantic error has incorrect meaning or logic, and runtime error occurs during execution.

5.1.5 Control Structures

Sequence executes statements in order, selection makes decisions, and iteration repeats statements.

5.1.6 Program Design Tools

An algorithm is a step-by-step solution, a flowchart represents the solution using symbols, and pseudocode describes program logic in simple language.

5.1.7 Number and Character Codes

Binary uses 0 and 1, BCD represents decimal digits in binary, ASCII represents characters using codes, and Unicode supports characters of many languages.

5.2 C Programming

5.2.1 Introduction and Features

C is a fast, structured, portable, general-purpose programming language widely used for system and application programming.

5.2.2 Structure of C Program

A C program generally contains headers, main(), declarations, statements, and return. 

#include 
int main() {
    printf("Hello");
    return 0;
}

5.2.3 Preprocessor and Header Files

The preprocessor handles # directives before compilation. Header files provide predefined functions, e.g. #include .

5.2.4 Character Set

C uses letters, digits, special symbols, whitespace, and escape characters.

5.2.5 Comments

Comments explain code and are ignored by the compiler: // comment or /* comment */.

5.2.6 Identifiers, Keywords and Tokens

Identifiers are user-defined names, keywords are reserved words such as int and if, and tokens are the basic elements of a program.

5.2.7 Data Types

Basic data types are char, int, float, double, and void.

5.2.8 Constants and Variables

A constant does not change, while a variable can change during execution.

5.2.12 I/O Functions

printf() displays output and scanf() accepts input. scanf("%d",&n); printf("%d",n);

5.2.13 Selection Statements

if, if-else, else-if, nested-if, and switch are used for decision-making. if(a>b) printf("A"); else printf("B");

5.2.14 Iteration Statements

while, do-while, and for are used for repetition. A loop inside another loop is called a nested loop. for(i=1;i<=5;i++) printf("%d ",i);

5.2.15 Array

An array stores multiple values of the same type. 1D uses one index and 2D uses rows and columns. int a[5]; int m[2][2]; Matrix addition/subtraction is done element by element: C[i][j] = A[i][j] ± B[i][j].

5.2.16 String

A string is a sequence of characters ending with \0. Common functions are strlen() for length, strcat() for joining, strcmp() for comparison, strcpy() for copying, and strrev() for reversing. strlwr() and strupr() convert strings to lowercase and uppercase, respectively.
