Web technology

.1 Introduction to Web Development

Web development is the process of creating websites and web applications using technologies such as HTML, CSS, JavaScript, servers, and databases.

6.2 Web Browsers and Search Engines

A web browser displays web pages, such as Chrome, Firefox, and Edge. A search engine helps find information on the Internet, such as Google and Bing.

6.3 Internet and Web Technologies

The Internet is a global network of connected computers, while the WWW provides web pages through the Internet. Common technologies are HTML, CSS, JavaScript, HTTP/HTTPS, URLs, and web servers.

6.4 CMS and HTML

A CMS (Content Management System) is software used to create and manage website content. HTML is the standard language used to structure web pages.

6.4.1 Objectives

HTML is used to create and organize text, images, links, tables, forms, audio, video, and graphics.
