.1 Introduction of Computer
1.1.1 Definition, Characteristics and Applications of Computer
A computer is an electronic programmable device that accepts data as input, processes it according to instructions, stores it, and produces meaningful information as output. The main characteristics of a computer are high speed, accuracy, large storage capacity, automation, reliability, versatility, and diligence. Computers are used in education, banking, business, communication, healthcare, entertainment, transportation, science, and government.

1.1.2 Evolution of Computer Technology
The evolution of computers is divided into five generations. The first generation used vacuum tubes, the second generation used transistors, the third generation used integrated circuits (ICs), the fourth generation used microprocessors, and the fifth generation uses advanced technologies such as artificial intelligence, machine learning, and natural language processing.

1.1.3 Measurement Unit of Processing Speed and Storage Unit
Computer processing speed is measured in Hertz (Hz). Common units are Kilohertz (KHz), Megahertz (MHz), and Gigahertz (GHz). Computer storage is measured in bit, byte, KB, MB, GB, and TB. One byte contains 8 bits, and approximately 1 KB equals 1,024 bytes.

1.1.4 Super, Mainframe, Mini and Microcomputers
A supercomputer is the most powerful type of computer and is used for complex calculations, scientific research, and weather forecasting. A mainframe computer is a large computer used by banks, governments, and large organizations. A minicomputer is a medium-sized computer used for organizational or departmental purposes. A microcomputer is a small computer such as a desktop, laptop, or personal computer.

1.1.5 Mobile Computing and Its Application
Mobile computing is the use of computing devices and wireless networks while moving from one place to another. It includes smartphones, tablets, and other portable devices. Mobile computing is used for mobile banking, online education, GPS navigation, e-commerce, social media, video calls, and entertainment.

1.2 Computer System and I/O Devices
1.2.1 Computer Architecture and Organization
Computer architecture refers to the functional design and features of a computer system, while computer organization refers to how the internal hardware components are arranged and connected. Architecture focuses on what the computer does, whereas organization focuses on how it performs those functions.

1.2.2 Components of Computer System
A computer system consists of input unit, processing unit, memory unit, storage, and output unit. The input unit accepts data and instructions, the processing unit processes them, the memory unit temporarily stores data, secondary storage stores data permanently, and the output unit presents the processed results. The basic process is Input → Processing → Output → Storage.

1.2.3 Microprocessor
A microprocessor is an integrated circuit that performs the functions of a CPU. Its important features include clock speed and word length. Clock speed indicates how many cycles a processor performs per second, while word length indicates the number of bits processed at one time. The main components of a microprocessor are the ALU, Control Unit, and registers.

1.2.4 Bus System
A bus is a communication pathway used to transfer information between computer components. The data bus carries data, the address bus carries the address of data or instructions, and the control bus carries control signals between different components.

1.2.5 Primary Memory
Primary memory is the memory directly accessible by the CPU. It includes RAM, ROM, cache, and buffer. RAM is temporary and volatile memory and mainly consists of SRAM and DRAM. ROM is permanent and non-volatile memory and includes PROM, EPROM, and EEPROM. Cache is very fast memory used to improve CPU performance, while a buffer temporarily stores data during data transfer.

1.2.6 Secondary Memory
Secondary memory is used to store data and programs permanently. It includes magnetic disks such as HDDs, flash memory such as SSDs and memory cards, optical disks such as CDs and DVDs, external storage devices, and memory sticks or USB drives. It generally provides greater storage capacity than primary memory.

1.2.7 Input Devices
Input devices are used to enter data and instructions into a computer. Common input devices include keyboard, mouse, scanner, light pen, OMR, OCR, BCR, MICR, touch screen, microphone, and digital camera. OMR reads marked information, OCR recognizes printed text, BCR reads barcodes, and MICR reads magnetic characters mainly found on bank cheques.

1.2.8 Output Devices
Output devices provide the processed information to the user. A monitor displays information on the screen and may use LCD or LED technology. Printers produce hard copies and include dot-matrix, inkjet, and laser printers. A speaker produces sound output from the computer.

1.2.9 Hardware Interfaces
Hardware interfaces allow a computer to communicate with external devices. A parallel port transfers multiple bits at the same time, while a serial port transfers data sequentially. USB ports are commonly used to connect peripherals and transfer data.
